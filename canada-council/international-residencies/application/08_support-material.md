# Support Material

STATUS: PARTIAL

Missing any required item makes the application ineligible. Assessors view about 10 minutes of material in total.

## Required

| Item | Notes | Status |
| --- | --- | --- |
| Arts and cultural CV | 3 pages max; one per member if a group | Open |
| Information about the host | Use the ZK/U portfolio PDF in this folder | Have source |
| Host letter | Must confirm participation, length of residency, and host contribution (accommodation, travel, networking) | Request from ZK/U |
| At least 1 work sample | Previous work from Dada Issues Collective Press | Open |

## File rules

- Names under 45 characters, no spaces or punctuation; prefix with 01, 02 for order.
- Images: JPEG, RGB. Audio/video: playable in VLC, 1080p, 60 fps max. Text: pdf, doc, docx, txt, rtf.
- Links: only SoundCloud, Vimeo or YouTube; put passwords in the description.
- No zip files or Google Drive, WeTransfer or Dropbox links.
- Up to 10 text files and 10 audiovisual files, 500 MB each.
