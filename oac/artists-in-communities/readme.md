# Project files for OAC Artists in Communities and Schools Projects\n\nThis directory contains draft materials for an Ontario Arts Council **Artists in Communities and Schools Projects** application for the community-engaged phase of *The Seer’s Prophecy* (working title), an original folk opera drawing on Norse mythology.\n\n## File index\n\n- **01_project-description.txt** – working draft of the overall project description and artistic concept.\n- **02_community-and-partners.txt** – notes and draft answers on the communities involved and partner organizations (e.g., Forest Courtyard Initiative, Hesperus Fellowship).\n- **03_activity-plan-and-timeline.txt** – step-by-step activity plan, timeline, and work plan table details.\n- **04_access-and-inclusion.txt** – plans for reducing barriers, access supports, and inclusive engagement strategies.\n- **05_budget-notes.txt** – budget assumptions, line-item rationales, and income/expense notes.\n- **06_support-material-notes.txt** – list and notes for artistic examples, CVs/bios, and partner letters.\n- **07_final-report-considerations.txt** – notes on documentation, evaluation, and final-report requirements.\n\n## Reference\n\nOfficial OAC program page: https://www.arts.on.ca/grants/artists-in-communities-and-schools-projects\n
